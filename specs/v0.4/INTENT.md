### 결정 기록

gpui v0.4와 이 레포 v0.2 사이에서 어긋난 점과 그 결정이다. 7·8은 사용자 결정(2026-11-06)이고, 나머지는 리더 결정(사용자 위임 2026-11-06)이다.

1. `Duration` 하드코딩: 이미 됨으로 보고 범위에서 뺀다.
   - 어긋남: gpui R-5는 남은 `Duration::from_*` 리터럴을 스펙 ID 상수로 옮겼다. 이 레포 코어에는 테스트 밖 리터럴이 이름 붙은 앱 상수 하나뿐이다.
2. clippy: `cargo clippy -- -D warnings` 0건을 Phase 1 완료 조건으로 두고, 루트 `AGENTS.md` 2장 명령에 더한다.
   - 어긋남: gpui R-6은 clippy 기준선 경고를 0건으로 만들었다. 이 레포 v0.2는 clippy를 돌리지 않아 기준선이 없다. clippy는 설치되어 있다.
3. 겹친 열기: 같은 탭에 열기 요청이 겹치면 마지막 요청만 반영하는 것을 탭 편집 요구에 넣는다.
   - 어긋남: gpui R-4의 일부다. 이 레포 v0.2 R-30은 UI를 막지 않는 것만 판정했다. 편집 버퍼가 늦게 온 열기 결과로 덮이면 데이터 손실이다(루트 `AGENTS.md` 4.3).
4. P4 UI 셸 대상: v0.2 끝 V3 결과(불일치 0)를 기준으로 두고, Phase 끝 V3 묶음에서만 잰다.
   - 어긋남: gpui D-3은 Phase 2 시작 때 UI 셸 전체를 V3로 재 불일치 목록을 만들었다. 이 레포는 같은 스펙 값으로 이미 V3를 통과했고, 다시 재는 것은 루트 `AGENTS.md` 3A.5에 걸린다.
5. 스펙 ID 없는 값: 원문 근거가 있는 것만 gpui에 toml ID 추가를 요청하고 ID가 생긴 것만 넣는다. 원문 근거가 없는 것(상태 표시줄 좌우 padding, L-40, I-508)은 기본값으로 둔다.
   - 근거: 스펙 밖 값은 지어내지 않는다(루트 `AGENTS.md` 3장). `spec/`의 원본은 gpui다. gpui도 사이드바 폭 조절(A-11.12)을 미결로 넘겼다(gpui v0.4 DECISIONS 미결 사항).

## 제외 범위

gpui v0.4 제외 범위를 03-tauri 7절 단계로 옮긴 것이다. 단서는 gpui v0.4와 같다.

- gpui PoC 7단계: 테마·아이콘 테마 매핑과 선택기, 내장 테마 번들, Zed 글꼴 자산. 03-tauri 7절 3단계의 아이콘 매핑, 7단계의 테마·아이콘 테마 선택기다(v0.2와 같음).
- gpui PoC 8단계: 찾기 창, Picker·Open Recent, 키맵 편집 화면, 확장, 그 밖의 상태 복원. 03-tauri 7절 5단계의 찾기 바, 7단계 나머지(Picker, 키맵 편집 화면, 키 녹화, About), 8단계(확장, 다중 창 복원, 일치도 판정)다. 탭·분할 상태 복원(I-112~I-120)도 뺀다(gpui D-7).
- 종료 때 미저장 내용 복원(A-25.8·I-118, gpui A2). 저장 질문으로 대신한다(gpui H-17과 같음).
- 03-tauri 7절 6단계의 뷰어 등록 구조(03-tauri R-26)와 이미지 뷰어(03-tauri R-18). 마크다운 미리보기만 넣는다(gpui v0.4 범위와 같음).
- 에디터를 직접 구현하는 것. CM6를 그대로 쓴다(gpui D-6 "편집기 유지"에 대응, v0.1).
- 에디터 코어의 모호 3건(E-012, E-034, E-049)과 큰 파일 + soft wrap(결정 기록 6).
- `Duration` 하드코딩 정리(결정 기록 1).
- 회귀 대조와 V3 → V2 레이아웃 테스트 이전(결정 기록 10·11).
- 원문 근거가 없는 기본값(상태 표시줄 좌우 padding, L-40, I-508)의 판정(결정 기록 5).
- 프로젝트 패널 드래그 앤 드롭(I-094), 외부 드롭 뒤 자동 열기(I-097), 프로젝트 패널 드래그로 열기(I-721·I-722)(결정 기록 9).
- 저장 때 줄 끝 공백 제거·마지막 줄바꿈(A-21.16, 04-APP-SPEC 4.2). gpui가 넣지 않았다(gpui D-6, gpui PROGRESS Phase 2 종료).
- ☰ 앱 메뉴에서 v0.4에 동작하지 않는 항목(v0.2와 같음).
- Zed 글꼴(`.ZedSans`·`.ZedMono`)과 Lilex 글꼴(v0.2와 같음).
- 패키징·서명(03-tauri R-29).
- 값이 없는 E-032 두께 판정(v0.1·v0.2와 같음).
- gpui 고유 작업: 큰 파일 분할(`folders.rs`·`dev.rs`), `watch.rs` epoch 함수 통합, gpui 저장소의 데스크톱 환경 맞추기. gpui 저장소에 대한 작업이다.
- v0.2 알려진 한계: 바깥에서 이름을 바꾼 펼친 폴더가 접힌 채 나타남, 감시 이벤트와 `rename_path` 응답 순서, 앱 안 파일 작업과 바깥 변경의 동시 경합, 휴지통 도착 판정 불가(v0.2 PROGRESS "버전 종료" 남은 것). gpui v0.4가 v0.2 한계를 뺀 것과 같다.
- 지난 버전 폴더(`specs/v0.1/`·`specs/v0.2/`)의 수정.
