## 4. 결론 (Zed 기본 동작 판정)

- **세로 스크롤바 표시 조건**:
  - Zed의 Windows 기본 환경(사용자 설정 기본값, Windows `DynamicScrollbars` 없음)에서 세로 스크롤바는 **마우스 위치(편집 영역 안, 타이틀 바, 창 바깥)와 무관하게, 그리고 스크롤 조작 여부나 시간 경과(1초, 3초)와 무관하게 상시 표시(Always Visible)**된다.
  - 마우스를 올렸을 때만 나타나거나 일정 시간 후 사라지는 자동 숨김(auto-hide) 동작은 관찰되지 않았다.
- **가로 스크롤바 표시 조건**:
  - 내용이 편집 폭을 넘지 않는 경우 가로 스크롤바는 표시되지 않는다.
- **ORDER-03 3.4 지침과의 관계**:
  - ORDER-03 3.4의 초기 기대("마우스가 편집 영역 위에 있을 때 스크롤바가 보이고, 벗어나면 사라진다")와 달리, 실제 Zed 기본값은 **상시 표시**임이 실측으로 확정되었다.
