# DECISIONS — workbench-tauri v0.2

## D-1. v0.1 결정 D-1~D-17·D-19를 이어받고, D-18(줄 수 비교)은 이어받지 않는다

**선택**

- v0.1 D-1~D-17, D-19를 v0.2에서도 따른다. 처리는 아래 "v0.1 결정 처리 표"에 있다.
- v0.1 D-18(버전 끝 `legacy-v0.1-poc`와 줄 수 비교)은 이어받지 않는다(리더 결정(사용자 위임 2026-11-05), Q-1).
- gpui 코드 값과 스펙 값이 다르면 스펙 값을 따른다(`specs/v0.2/INTENT.md` 결정 기록 14). 이 규칙은 아래 모든 결정에 걸린다.

**근거**

- v0.1 결정은 대부분 버전과 무관한 구현 방식이다(스택, CSP·`zlext`, 측정 코드 금지, 검증 수준, 커밋).
- WORKFLOW 5절: 지난 버전 폴더는 그대로 두고 읽기만 한다. 그래서 이 문서에서 이어받는다고만 적는다.
- v0.2 INTENT 기대 결과에는 줄 수 비교가 없다. v0.1 D-18은 v0.1 INTENT 기대 결과에서 나왔다.

**배제한 대안**

- **v0.1 결정을 모두 새 번호로 다시 쓴다** — 내용이 같은 결정이 두 곳에 생긴다. gpui v0.2 D-1도 이어받는다고만 적었다. 배제.
- **v0.1 D-18을 이어받아 v0.2 끝에도 줄 수를 비교한다** — v0.2 INTENT 기대 결과에 없다(리더 결정(사용자 위임 2026-11-05)). 배제.

## D-2. 앱 내장 키맵은 02 1절 키 표의 적용 결과를 다시 적은 것이고, 그 위에 사용자 `keymap.json`을 얹는다

**선택**

- 내장 키맵은 01-zed 02-INTERACTION 1절 키 표(Windows 기본 + VSCode 덧씌움 적용 결과, I-001·I-700)에서 v0.2에 있는 액션만 골라 다시 적은 것이다.
- 사용자 `keymap.json`(A-20.4, Zed와 같은 객체 배열)을 그 위에 마지막으로 얹는다(A-27.1).
- `base_keymap` 설정은 만들지 않는다. 항상 VSCode 덧씌움 결과를 쓴다(A-27.2).
- 액션 이름: 01-zed에 이름이 있으면 그대로 쓰고, 없으면 `namespace::Name` 꼴로 짓는다. gpui가 지은 이름이 있으면 같은 이름을 쓴다(gpui v0.2 D-2 이후 변경). 지은 이름 목록은 PROGRESS에 남긴다.
- ☰ 메뉴의 Quit(Ctrl+Q)과 Close Window(Ctrl+Shift+W)도 내장 키맵에 넣는다(gpui v0.2 D-2 이후 변경, A-18.11).

**근거**

- `specs/v0.2/INTENT.md` 범위(키맵 로더, 결정 기록 2)와 목적("gpui v0.3까지 구현한 상태와 같은 동작").
- gpui v0.2 D-2: Zed 키맵 JSON 원문은 가져오지 않는다는 라이선스 원칙 때문에 적용 결과를 다시 적는다. 이 레포도 Zed 코드 복사 금지다(루트 `AGENTS.md` 레포 규칙).

**배제한 대안**

- **Zed 키맵 JSON 원문을 넣고 실행할 때 합친다** — 원문을 가져오지 않는다(gpui v0.2 D-2와 같은 이유). 배제.

## D-3. 키 규칙은 I-702·I-703·I-704와 L-217~L-221을 따르고, v0.1의 WebView 자체 엔진(v0.1 D-4)을 넓혀 쓴다

**근거**

- 01-zed I-702·I-703·I-704, L-217~L-221. v0.1 P2-2에서 엔진이 I-702·I-703·I-001·I-704를 따른다(`specs/v0.1/PROGRESS.md` P2-2).

**배제한 대안**

- **키맵 라이브러리로 바꾼다** — v0.1 D-4에서 배제했다. 배제.

## D-4. `keymap.json`은 주석·끝 쉼표를 허용하고, 코어가 문자열로 주면 WebView가 읽는다

**선택**

- 코어는 `keymap.json` 파일 문자열만 준다. WebView가 주석(`//`, `/* */`)과 끝 쉼표를 걷어 낸 뒤 `JSON.parse`로 읽는다. 걷어 내는 코드는 직접 쓴다(새 의존성 없음).
- 비자명한 파싱이라 테스트 하나를 둔다(`AGENTS.md` 4.4).

**근거**

- 리더 결정(사용자 위임 2026-11-05), Q-2 (다).
- gpui v0.2 D-4: 사용자 결정으로 JSONC 허용. "gpui와 같아야 한다"(INTENT).
- 키맵 엔진이 WebView에 있다(v0.1 D-4).
- `AGENTS.md` 5장: 의존성은 03-tauri 3.1·3.2 목록 안에서만 고른다.

**배제한 대안**

- **코어가 `serde_json`으로 엄격 JSON만 읽는다** — 주석·끝 쉼표가 막혀 gpui와 달라진다. 배제.
- **코어가 `jsonc-parser`로 읽는다(gpui v0.2 D-4)** — 03-tauri 3.1 목록에 없다. 배제.

## D-5. 메뉴·툴팁은 DOM으로 직접 그린다

**선택**

- ☰ 앱 메뉴, 우클릭 메뉴, 툴팁은 WebView DOM으로 직접 그린다. `tauri::menu` 네이티브 메뉴는 쓰지 않는다.
- 브라우저 기본 우클릭 메뉴는 막는다. 입력칸의 복사·붙여넣기는 남기는 규칙을 SPEC에서 정한다(03-tauri R-25).
- 툴팁은 전역 하나로 둔다(03-tauri 4절 툴팁 행).

**근거**

- 01-zed I-301: Windows의 Zed는 직접 그린 메뉴를 쓴다.
- 03-tauri 3.3 메뉴·툴팁 행(DOM), 4절 메뉴·툴팁 행, R-25("`tauri::menu`는 모양·가로 메뉴 바·단축키 표시를 맞출 수 없다").
- gpui v0.2 D-5 이후 변경도 결국 직접 그렸다.

**배제한 대안**

- **`tauri::menu` 네이티브 메뉴** — 모양·가로 메뉴 바·단축키 표시를 맞출 수 없다(03-tauri R-25). 배제.

## D-6. 앱 데이터 폴더는 `%APPDATA%\workbench-tauri`다

**선택**

`keymap.json`·`state.json`을 `%APPDATA%\workbench-tauri\`에 둔다. 경로는 Tauri 경로 API나 코어의 `APPDATA` 환경변수로 얻는다(새 의존성 없음).

**근거**

- 리더 결정(사용자 위임 2026-11-05), Q-3 (가).
- gpui v0.2 D-11과 같은 꼴(앱 이름 폴더)이다. 두 앱이 서로의 `state.json`을 덮어쓰지 않는다.
- 01-zed A-20.3은 `%APPDATA%\ZedLike\`를 임시 이름으로 둔다. `src-tauri/tauri.conf.json`의 `productName`은 `workbench-tauri`다.

**배제한 대안**

- **Tauri `app_data_dir()` 기본값** — identifier(`dev.workbench.tauri`)를 따라 `%APPDATA%\dev.workbench.tauri\`가 되어 앱 이름 폴더와 다르다. 배제.
- **gpui와 같은 `%APPDATA%\workbench-gpui\`** — 두 앱이 같은 파일을 읽고 쓴다. 배제.

## D-8. 등록 폴더 하나가 독립 항목이고, 폴더마다 작업 문맥을 따로 둔다

**선택**

- 폴더 하나에 루트 하나다(A-10.3). 여러 폴더를 골라도 폴더마다 독립 항목이다(A-10.6). 선택 창은 폴더 하나만 고른다.
- 폴더 id를 키로 열린 탭·트리 펼침·선택·스크롤을 따로 보관한다. 전환해도 이전 폴더의 문맥은 메모리에 남는다(A-15, I-108, I-111).
- 문맥은 WebView 쪽 상태로 두고, 저장은 화면이 스냅샷을 코어에 보내 코어가 쓴다(03-tauri 2.4 "저장 요청").
- 사이드바에는 활성 폴더와 별도로 키보드 커서를 둔다(gpui v0.2 D-7 이후 변경, A-17.3, A-12.5).

**근거**

- gpui v0.2 D-7, 01-zed A-10.3·A-10.6·A-15·I-108·I-111.
- 03-tauri 2.4. v0.1의 `EditorView`를 Solid 밖에 두는 방식(v0.1 P1-1, 03-tauri 6절 두 번째 행)을 탭 편집기에도 쓴다.

**배제한 대안**

- **한 프로젝트에 여러 루트(multi-root)** — I-111이 요구와 다르다고 했고, A-18.4가 "Add Folder to Project…"를 앱 메뉴에서 뺐다(gpui v0.2 D-7). 배제.
- **문맥을 코어(Rust)에 둔다** — 화면 갱신마다 IPC가 필요하다. 03-tauri 2.4는 화면이 상태를 갖고 코어가 쓴다. 배제.

- 아이콘은 앱 번들 자산이라 `zlext`나 CSP 항목을 더하지 않는다.
- 아이콘 테마 매핑과 v0.1의 Catppuccin 고정 아이콘은 쓰지 않는다(INTENT 결정 기록 3).

**근거**

- 리더 결정(사용자 위임 2026-11-05), SPEC 작성 중 Q-D(개정 2026-11-05).
- "workbench-gpui와 같아야 한다"(루트 `INTENT.md`). 01-zed T-10.21은 사이드바 폴더 아이콘을 `Folder`로 적는다.

**배제한 대안**

- **v0.1처럼 설치된 `catppuccin-icons` 확장의 SVG를 `zlext`로 쓴다** — gpui 화면과 아이콘이 달라진다(리더 결정(사용자 위임 2026-11-05)). 배제.
