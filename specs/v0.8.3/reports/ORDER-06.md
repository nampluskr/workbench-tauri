- **I-29 선택 영역·현재 줄**: 선택 사각형 왼쪽 끝은 글 영역 왼쪽 끝(+줄 왼쪽 여백)보다 왼쪽으로 가지 않는다(CodeMirror `leftSide`) — 줄 번호 칸 끝과 같은 x라 가리는 부분이 없다. 현재 줄은 `.cm-activeLine::before { inset: 0 }`로 줄 상자만, 줄 번호 쪽은 `.cm-activeLineGutter`가 따로 칠한다. 모든 칸의 커서가 0.6px 오른쪽(글자 왼쪽 끝에서 시작)으로 가고 줄 번호를 끈 에디터도 같다.
