# DECISIONS — workbench-tauri v0.1

## D-1. Zed를 포크하지 않고 reverse engineering으로 재구현한다

**선택**

Zed 저장소를 포크하지 않는다. Zed의 화면·동작·치수 같은 사실을 명세로 적고, 그 명세대로 새로 만든다.

재구현은 두 갈래다.
- workbench-gpui: gpui-kit 기반
- 이 프로젝트(workbench-tauri): Tauri 기반

두 갈래는 외형·기능·레이아웃이 같은 같은 앱이고, 둘 다 같은 Zed 명세(01-zed)로 대조한다.

**근거**

루트 `INTENT.md`의 원칙 "포크가 아니라 재구현이다"를 따른다. 이 원칙은 사용자가 확인했다(2026-11-01). 03-tauri 1절 "방식" 행도 "포크가 아니라 reverse engineering 재구현"이다.

두 갈래의 기술 사실은 사용자 지시에서 나왔다(2026-11-01). 원문은 다음과 같다.

> "zed like editor 에 대하 gpui kit / tauri 기반의 2갈래 동일한 외형/기능/레이아웃을 가진 결과물이 나와야 합니다."

루트 `INTENT.md`에는 기술 이름 없이 "workbench-gpui와 같아야 한다"는 원칙만 둔다. 기술 이름은 이 결정으로 옮겼다(리뷰 지적 11, 사용자 결정 2026-11-01, DOCUMENTS.md 3절 "담지 않는 것"). zed-like-editor README도 "그 명세를 gpui-kit(1순위)과 Tauri 2(2순위)로 구현한다"고 적었다.

**배제한 대안**

- **Zed 포크** — 루트 `INTENT.md` 원칙과 03-tauri 1절이 재구현으로 정했다. 배제.

## D-3. 프런트엔드 UI 프레임워크는 Solid(`solid-js`)로 한다

**선택**

프런트엔드는 Solid(`solid-js`)로 만든다. 이 선택은 v0.1 Phase 1의 R-01 PoC(03-tauri R-01)로 확인한다. PoC가 실패하면 React 19를 대안으로 비교한다.

**근거**

leader가 Solid·Svelte 5·React 19를 비교해 Solid를 추천했고, 사용자가 골랐다(2026-11-01). 03-tauri 3.2·3.3은 이 항목을 "미정 (R-01)"으로 두고, "세밀한 반응성이 유리하다는 가설"을 적었다. 비교에서 든 Solid의 이유는 다음과 같다(leader 비교, 2026-11-01).
- 갱신이 signal 단위다.
- 컴포넌트가 실제 DOM 노드를 돌려준다. 그래서 미리 만든 `EditorView` 노드를 그대로 끼워 넣기 쉽다(03-tauri R-01).
- 런타임이 약 7KB다.
- workbench-gpui의 Entity + notify 모델과 비슷하다.

위험은 props 구조 분해 같은 반응성 함정이다. 이것은 reviewer의 리뷰 항목으로 둔다(PLAN).

**배제한 대안**

- **React 19** — 가상 DOM이 노드를 소유한다. 부모가 바뀌면 다시 마운트되므로 `EditorView`를 옮기려면 ref와 수동 `appendChild` 같은 우회가 필요하다. 런타임도 약 45KB 이상으로 무겁다. 생태계와 에이전트 코드 정확도는 높다. R-01 PoC가 실패할 때의 대안으로 남긴다(leader 비교, 사용자 결정 2026-11-01).
- **Svelte 5** — 갱신은 세밀하지만 rune 문법이 새로워 Svelte 4 문법을 섞어 쓰는 실수가 잦다(leader 비교, 사용자 결정 2026-11-01). 배제.

## D-5. 키맵 엔진은 WebView 쪽에 자체 엔진으로 둔다

**선택**

키맵 평가는 WebView 프런트엔드의 자체 엔진이 한다. 이 엔진이 평가하는 것은 컨텍스트 깊이 우선, 출처 등급, 연속 키, 메뉴·툴팁에 표시할 키 조회다.

**근거**

**배제한 대안**

- **코어(Rust)에서 평가** — 사용자가 WebView 쪽 엔진을 골랐다(2026-11-01). 배제.
- **키맵 라이브러리** — 03-tauri 3.3이 같은 규칙을 한 곳에 두려고 자체 엔진을 골랐다. 사용자도 이를 골랐다(2026-11-01). 배제.
