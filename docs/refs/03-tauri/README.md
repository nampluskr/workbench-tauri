# 03-tauri · Tauri 프로젝트 출발 문서

> 이 파일을 읽는 때: Zed 같은 편집기를 Tauri 2 + 웹 프런트엔드로 **별도 프로젝트**에서 만들기 시작할 때. 무엇을 만들지와 구현 전에 확인할 것의 목록이다.

| 항목 | 내용 |
| --- | --- |
| 상태 | **출발 문서.** 구현 코드와 상세 절차는 없다. 전체 내용과 "구현 전에 확인할 목록"만 담는다 |
| 기준 버전 | Windows 11, Rust 1.99.1, Tauri 2.12.5, WebView2 런타임, Zed 커밋 [14b7b0e](https://github.com/zed-industries/zed/commit/14b7b0ef3764d62a85070c8b5ccea105a2ad3235). 크레이트·패키지 버전은 2026-10-31 조사·조회값이고 구현 때 다시 확인한다 |
| 명세 기준 | [../01-zed/](../01-zed/)의 01~04. 항목 ID로 참조한다: 01-LAYOUT(`L-`), 02-INTERACTION(`I-`, 조사 ID `E-`·`P-`·`K-` 포함), 03-THEME-ICONS(`T-`), 04-APP-SPEC(`A-`, 확장 조사 `X-`) |
| 짝 문서 | [../02-gpui/README.md](../02-gpui/README.md) (같은 절 번호·제목). 구현 순위는 gpui 가 1순위, Tauri 가 2순위지만 명세는 같은 수준으로 맞춘다 |
| 표기 | **확정** = 01-zed 가 정한 것, **판단** = 작성자 판단, **미확인** = 확인하지 못함. 원본 재료의 표기를 그대로 두었다 |
| 검증 | 실행 검증 안 함. 크레이트 정보는 crates.io·npm·docs.rs 기준 |

## 1. 이 문서의 역할

| 항목 | 내용 |
| --- | --- |
| 무엇 | 구현은 별도 프로젝트에서 한다. 이 문서는 그 프로젝트가 가져가는 **출발(참고) 문서**다 |
| 기준 | 동작·치수·색·키·문구는 모두 [01-zed/](../01-zed/) 가 정한다. 이 문서는 값을 다시 정하지 않고 ID 로 가리킨다 |
| 포함하는 것 | 전체 구조, 기술 스택 후보, 01-zed 항목과 구성 요소의 연결, 구현 전에 풀어야 할 상세 조사·검토 항목(5절), 위험 요소, PoC 시작 순서 |
| 포함하지 않는 것 | 코드, 상세 구현 절차, 확정되지 않은 값의 추정 |
| 표기 | **확정**은 01-zed 가 정한 것, **판단**은 이 문서의 제안, **미확인**은 확인하지 못한 것이다 |
| 방식 | 포크가 아니라 reverse engineering 재구현이다. Zed 의 앱 코드(GPL-3.0)는 가져오지 않는다 (README 3절) |

범위는 README 요건 1~7 과 사용자 결정(`_decisions.md`)이다. 요약:

- 멀티 폴더 사이드바 + 폴더 트리 + 탭·분할·핀 + 마크다운 미리보기·이미지 뷰어 + 코드 편집(구문 강조)
- ☰·∨·우클릭 메뉴, 툴팁, 찾기·바꾸기, 명령 팔레트, Go to File, Open Recent, 키맵(VSCode 적용)·키맵 편집 화면, 새 창
- 테마 6종·아이콘 테마 5종 선택, **내장**(One, Zed (Default), Catppuccin 4종·Catppuccin Icons)
- 확장: 테마·아이콘 테마·언어(문법·구문 강조)만, 로컬 설치만, 확장 화면 있음, 끄기 없음
- 제외: 터미널, Git, AI, LSP, 디버거, 원격, 온라인 확장 목록, 프로젝트 전체 검색, Settings UI

### 2.4 코어와 화면 사이의 약속 (판단)

| 항목 | 규칙 | 근거 |
| --- | --- | --- |
| 명령(`invoke`) | 파일 읽기·쓰기, 폴더 스캔, 휴지통, 설치·제거, 선택 창, 확인창은 코어 명령으로 한다. 반환은 작은 JSON 이다 | R-10 |

| 보안 | 화면은 확장 폴더 안의 파일만 요청한다. 경로 검증은 코어가 한다 | A-55.2 |

### 6.1 확신 낮은 부분

- **창 스냅·둥근 모서리 (R-06):** 장식 없는 창에서 Windows 11 의 스냅 레이아웃과 비최대화 모서리·테두리(L-311)가 함께 되는지는 미확인이다. `WM_NCHITTEST` 처리가 필요할 수 있다.
- **WebView2 가속키 (R-20):** 가로채는 키 가운데 확실한 것과 시험할 것을 나눴다(`Ctrl+W`, `F1`, `F6` 은 근거 없음). `AreBrowserAcceleratorKeysEnabled` 를 Tauri·wry 가 노출하는지, CSP 기본값(R-36)이 무엇인지는 공식 문서 링크만 걸었고 본문을 대조하지 않았다.
- **문법 WASM 호환 (R-03, R-19):** `web-tree-sitter` 0.27.1 이 Zed 확장의 문법 모듈(`wasi-sdk` `clang` 으로 만든 공유 모듈)을 읽는지, Zed 고유 지시문(`#set!`, `overrides.scm` 의 `.inclusive`)을 해석기가 따로 처리해야 하는지는 PoC 전까지 미확인이다.
- **CM6 ↔ Tree-sitter (R-37):** 증분 파싱·보이는 범위 장식의 성능은 측정 전이다.
- **이미지 뷰어 (R-18):** 지원 확장자·replace 여부·확대·배경은 조사 대기다(A-47.6).
- **개발용 확장 설치 (R-13):** 문법 컴파일(`wasi-sdk`) 포함 여부와 심볼릭 링크·정션 선택은 기술 확인으로 넘긴 항목이다(A-57.3).
- **OS 밝기 변경 감지 (R-34):** 창 테마 변경 이벤트와 `prefers-color-scheme` 가 WebView2 에서 모두 오는지는 미확인이다(A-60.12). 확장을 읽는 중의 폴백·선택기 규칙 자체는 확정이다(A-60).
- **언어 선택 규칙 (R-35):** 규칙은 확정이고(A-59), 우리 앱의 내장 언어 목록은 정하지 않았다(A-40.17).
- **크레이트·패키지 버전:** 2026-10-31 조사·조회값이다. `windows`, `tar`, `flate2`, `tauri-plugin-window-state` 의 라이선스는 구현 때 확인한다. `nucleo-matcher`(MPL-2.0)는 파일 단위 카피레프트라 정적 링크 배포에는 문제없다고 보지만 판단이다.
- **상태 복원 플러그인 (R-21):** `tauri-plugin-window-state` 가 다중 창·다중 모니터·배율 변경을 어떻게 다루는지는 미확인이다.
